# راهنمای انتخاب ویدیوی مرجع (Reference)

> LOCK-12 (v2.5.1): هیچ رفرنسی باندل نمی‌شود. شما رفرنس خودتان را وارد می‌کنید تا
> هم مسئلهٔ کپی‌رایت حل شود و هم سبک خروجی دقیقاً «سبک خودتان» باشد.

## چرا رفرنس شخصی؟
موتور Style Match امضای تدوین (طول کات، نوع نما، ریتم، رنگ، ترنزیشن) را از رفرنس
استخراج می‌کند. هر چه رفرنس به سلیقهٔ نهایی شما نزدیک‌تر باشد، خروجی به همان سبک
نزدیک‌تر می‌شود. کلیپی که سبکش را دوست دارید اما خودتان نساخته‌اید، در نهایت
«کپی سبک دیگران» است — نه امضای شما.

## مسیر پوشه
```
%APPDATA%/CuttingEdgeV2/references/
```
اپلیکیشن این پوشه را در اولین اجرا می‌سازد. فایل‌ها را مستقیم داخل آن کپی کنید یا از
UI با drag-drop اضافه کنید (Import Reference Videos).

## مشخصات فنی پیشنهادی
| مورد | مقدار |
|---|---|
| کدک | H.264 (MP4) یا ProRes |
| رزولوشن | حداقل 1080×1920 برای خروجی عمودی |
| نرخ فریم | 30 یا 60 (ثابت) |
| طول | 30 ثانیه تا 3 دقیقه (کوتاه‌تر = تحلیل سریع‌تر) |
| صدا | ترجیحاً با موسیقی، برای تحلیل beat-cut |
| تعداد | ۱ رفرنس کافی است؛ حداکثر ۳ رفرنس برای مقایسه |

## از چه چیزی پرهیز کنید
- ویدیوی با واترمارک سنگین یا زیرنویس سوخته (تحلیل نما را خراب می‌کند)
- ترنزیشن‌های AI سنگین و افکت‌های تصادفی
- کلیپ‌های کمتر از ۱۵ ثانیه (توزیع طول کات بی‌معنی می‌شود)
- ویدیوی کسی دیگر بدون اجازه، اگر قصد انتشار عمومی خروجی را دارید

## موزیک
- فقط CC0 یا CC-BY (با attribution) در `%APPDATA%/CuttingEdgeV2/music/`
- منابع پیشنهادی: freesound.org (فیلتر CC0), pixabay.com/music (CC-BY)
- فایل MP3/WAV، ترجیحاً با BPM مشخص در نام فایل (مثل `track-128bpm.mp3`)

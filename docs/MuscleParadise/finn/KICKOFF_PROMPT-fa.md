# پرامپت آغاز — تحویل به هوش مصنوعی برای ساخت کامل Muscle Paradise

> این متن را کپی و به هر ایجنت هوش مصنوعی (Claude، ChatGPT، Arena و...) بدهید. وظیفهٔ آن: ساخت کامل پروژه بدون نظارت شما.

---

نقش تو: تو مجری خودکار پروژهٔ «Muscle Paradise» هستی — یک سیستم‌عامل باشگاه (اپ موبایل عضو + پنل مربی/مدیر + کیوسک داخل باشگاه + ورود با تشخیص چهره + موتور برنامه‌ریزی شخصی تمرین و تغذیه). وظیفهٔ تو: ساخت کامل این برنامه از صفر تا محصول نهایی، **بدون نظارت انسانی و بدون توقف برای پرسیدن سؤال**.

اسناد مرجع (اول دانلود و کامل بخوان):
📦 https://raw.githubusercontent.com/yousefghorbanian98-create/Cutting-Edge-Studio./mp-fin-v1/delivery/muscle-paradise-fin-v1.zip
(داخل زیپ: `MuscleParadise/FINN_LOOP.md` = پروتکل اجرایی، `MuscleParadise/16_LAYER_PRODUCTION_PLAN.md` = طرح فنی محصول، `MuscleParadise/finn/install-ecc.sh` = نصب‌کنندهٔ ECC)
اگر دانلود ممکن نبود، همان فایل‌ها را از مسیر `docs/MuscleParadise/` مخزن بردار.

قوانین اجرایی (خلاصهٔ FINN Loop — چرخهٔ Forge ساخت → Inspect بازبینی → Normalize نرمال‌سازی → Next گام بعد):

۰. **فاز صفر، قبل از هر کاری:** ECC (Everything Claude Code) را با اجرای `install-ecc.sh` (یا دستورات دستی بخش ۳.۲ سند FINN_LOOP) در فضای کاری نصب کن. تا ۹ ایجنت (`planner`، `architect`، `tdd-guide`، `build-error-resolver`، `code-reviewer`، `e2e-runner`، `refactor-cleaner`، `security-reviewer`، `doc-updater`) نصب و تأیید نشده‌اند، شروع نکن.

۱. میکرو-چرخه‌های **M00 تا M17** را **پشت سر هم** و به ترتیب اجرا کن (جدول نگاشت بخش ۶ سند FINN_LOOP). هر میکرو-چرخه دقیقاً ۴ فاز را طی می‌کند:
   - **Forge:** `planner` → `architect` → `tdd-guide` → پیاده‌سازی → `build-error-resolver` (تا سبزشدن build/test)
   - **Inspect:** `code-reviewer` → اجرای کامل تست‌ها → `e2e-runner`
   - **Normalize:** `refactor-cleaner` → `security-reviewer` → رفع نهایی
   - **Next:** `doc-updater` → به‌روزرسانی LEDGER/STATE/REGRESSIONS → commit

۲. در هر گام، **ایجنت ECC مشخص‌شده را فراخوانی کن**: در Claude Code به‌صورت subagent با همان نام؛ در چت معمولی، محتوای فایل `.claude/agents/<name>.md` را به‌عنوان نقش و روش‌شناسی همان گام بخوان و دقیقاً با همان نقش اجرا کن. در گزارش هر گام بنویس کدام ایجنت اجرا شده است.

۳. **دیباگ در هر مرحله:** حداکثر ۳ تلاش رفع برای هر خطا؛ بعد از سومین شکست، rollback به آخرین کامیت سبز + بازطراحی رویکرد با `planner` (نه تکرار همان روش). هیچ تست شکسته‌ای را skip/ignore نکن؛ گیت قرمز = چرخه تمام نشده.

۴. **ضدتکرار و جلوگیری از اشتباه:** آغاز هر چرخه `LEDGER.md` را کامل بخوان؛ هر باگ = حداقل یک تست رگریشن در `REGRESSIONS.md`؛ هر تصمیم خودمختار = ثبت در `DECISIONS.md`؛ هر تصمیم معماری = ADR در `docs/MuscleParadise/adr/`؛ قبل از ساخت هر چیز جست‌وجوی کد موجود کن (ساخت ماژول/تابع تکراری ممنوع)؛ «درس تکراری» در Ledger = شکست چرخه.

۵. **گیت‌های پایان هر میکرو-چرخه (همه اجباری):** build سبز؛ پوشش تست بک‌اند ≥ ۷۰٪ بدون کاهش؛ لینت/فرمت صفرخطا؛ `bandit` + `pip-audit` بدون بحرانی جدید؛ گزارش `code-reviewer` بدون Blocker؛ مستندات و CHANGELOG به‌روز؛ یک commit با پیام `mp(Mxx): <summary> [finn]`.

۶. **توقف ممنوع:** هرگز برای پرسیدن سؤال از انسان متوقف نشو. در ابهام، تصمیم بگیر، در `DECISIONS.md` ثبت کن، ادامه بده. فقط دو گزارش مجاز است: گزارش پایان موفق، یا مانع خارج از کنترل که پس از ۳ تلاش + مسیر جایگزین حل نشده باشد.

۷. **میدان کار:** کد فقط زیر `mp-app/`، مستندات فقط زیر `docs/MuscleParadise/`؛ پوشهٔ `ce-app/` هرگز دست نخورد؛ commit تمیز و push فقط به شاخهٔ جاری.

۸. **استاندارد کیفیت = کلاس جهانی** (تعریف عملیاتی بخش ۱۰ سند FINN_LOOP): درستی (همهٔ معیارهای پذیرش)، پایداری (تست و رگریشن)، امنیت (OWASP، رمزنگاری دادهٔ بیومتریک، audit log)، کارایی (SLO گیت ورود < ۲ ثانیه)، تجربهٔ کاربری (فارسی RTL کامل، فونت Vazirmatn، حالت تاریک)، مهندسی (ADR، بدون کد مرده/تکراری)، مستندات همگام، بازتولیدپذیری (نصب ECC با کامیت ثبت‌شده، migration از صفر).

**خروجی نهایی:** فایل `finn/FINAL_REPORT.md` شامل شواهد واقعی (خروجی تست‌ها، درصد پوشش، نتایج اسکن امنیت، فهرست ADRها، وضعیت LEDGER) — نه ادعای متنی.

همین حالا از فاز صفر شروع کن و بدون توقف تا پایان M17 ادامه بده.

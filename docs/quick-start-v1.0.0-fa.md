# کاتینگ اج v2 — شروع سریع (۵ دقیقه)

1. **اجرا** کنید و منتظر سبز شدن نشانگر نوار وضعیت بمانید (اتصال هستهٔ محلی).
2. **ورود کلیپ‌ها** — ۱۰ کلیپ را روی پنل رسانه رها کنید (MP4/MOV/MKV، H.264 یا HEVC).
3. **انتخاب رفرنس** — ستارهٔ کارت ویدیوی مرجع را بزنید. کلیپ ۱۵ تا ۴۵ ثانیه‌ای با کات‌های
   تمیز بهترین نتیجه را می‌دهد.
4. **بررسی سازگاری** — اگر فوتیج کم باشد یا نسبت تصویر متفاوت باشد هشدار می‌گیرید؛ هشدار
   قرمزِ *block* یعنی «کلیپ بیشتری اضافه کنید».
5. **ساخت EDL** — ویزارد DNA تدوین را استخراج می‌کند (طول کات، ترکیب نما، حرکت دوربین، رنگ،
   شبکهٔ ضرب) و لحظه‌های اوج شما را روی همان ریتم می‌چیند.
6. **پس‌تولید** — ریپلی، زیرنویس خودکار و یکسان‌سازی صدا را فعال کنید، پلتفرم را انتخاب
   (پیش‌فرض: تیک‌تاک ۹:۱۶) و **ساخت پیش‌نمایش** را بزنید.
7. **رندر نهایی** — در صورت وجود GPU با NVENC H.264، در غیر این صورت openh264. خروجی در
   پوشهٔ `Exports/` کنار پروژه ذخیره می‌شود.

## کلیدهای میان‌بر

| کلید | کار |
|---|---|
| `Space` | پخش / توقف |
| `S` | برش در محل پلی‌هد |
| `M` | بوکمارک |
| `Del` | حذف انتخاب |
| `Ctrl+Z` / `Ctrl+Shift+Z` | واگرد / ازنو |
| `+` / `-` | بزرگ‌نمایی تایم‌لاین |
| `Ctrl+K` | پالت دستورها |

## محدودیت‌های صادقانهٔ نسخهٔ 1.0.0

- تطبیق سبک یک بازسازی **قاعده‌محور** از رفرنس است، نه کپی فریم‌به‌فریم: شباهت سبکی ۸۵ تا
  ۹۵ درصد انتظار معقولی است.
- زیرنویس با faster-whisper `base` تولید می‌شود؛ لهجه‌های خاص نیاز به بازبینی دستی دارند.
- اعداد کارایی و آزمون یکپارچگی باید روی **دستگاه خودتان** اندازه‌گیری شود؛ دستورها در
  `docs/TEST-PLAN.md` آمده است.
